# Task: wt-discovery (trackers, DHT, WebTorrent/WebRTC, web seeds) — pure Rust port
Target: engine-rs/crates/wt-discovery/ only.
Change: Port engine-go/patches/torrent/{tracker,webtorrent,webseed}, client-tracker-announcer.go, dht.go usage (anacrolix/dht v2 behaviour), bep40.go, and the engine-side tracker transport tracking needs, to async Rust (tokio).
Required public API (publish skeleton FIRST, compiling, then implement):
- `tracker`: AnnounceRequest/AnnounceResponse/AnnounceEvent; HTTP(S) announce (compact + dict peers, v4/v6, failure reason, warning, interval/min interval, user agent, custom dialer hook so the engine can route/track sockets) and UDP (BEP 15 connect/announce, retries/timeouts like Go, BEP 41 path); scrape optional; a per-torrent announcer/dispatcher that schedules announces per tier like client-tracker-announcer.go and emits status events (connected/disconnected/announce ok/error) matching wt_core::StatusEvent semantics.
- `dht`: BEP 5 mainline DHT node (routing table, get_peers iterative lookup, announce_peer with implied_port, token handling, bootstrap nodes from Go defaults, read-only mode off), ability to export/import good contacts (engine persists them), add nodes, periodic announce of torrents; you may build on the pure-Rust `mainline` crate if it supports these, otherwise implement. Must share or coexist with uTP's UDP socket — coordinate the interface with wt-wire's utp module (read it; ask coordinator if unclear).
- `webtorrent`: WebSocket tracker client (wss, offers/answers signaling exactly like anacrolix/torrent/webtorrent), WebRTC data channels via a pure-Rust WebRTC crate (webrtc-rs) with the ICE/STUN server list from engine-go/server.go; yields peer streams (AsyncRead+AsyncWrite) for the core to run the BitTorrent wire protocol over; bounded resources (offer limits, cleanup of stale offers).
- `webseed`: BEP 19 HTTP range fetches for a piece's file spans with concurrency limits, like patches/torrent/webseed.
- `bep40::priority(a, b) -> u32` exactly as Go.
Constraints: pure Rust TLS (rustls with ring), no OpenSSL; timeouts everywhere; bounded memory.
Observable acceptance: port tracker/*_test.go, bep40_test.go, webseed tests; local HTTP + UDP tracker tests (spin up in-process fake trackers); DHT test with several local nodes finding each other's announced peers; WebSocket tracker signaling test with a local fake tracker and two in-process WebRTC peers exchanging 4 MiB over a data channel.
