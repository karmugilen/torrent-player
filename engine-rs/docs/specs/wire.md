# Task: wt-wire (peer wire protocol, MSE, uTP) — pure Rust port
Target: engine-rs/crates/wt-wire/ only.
Change: Port engine-go/patches/torrent/{peer_protocol,mse}, handshake.go, ltep.go and peer message handling primitives to async Rust (tokio), plus a pure-Rust uTP (BEP 29) transport.
Required public API (publish skeleton FIRST, compiling, then implement):
- Handshake: reserved bits (ext, fast, DHT, v2 upgrade), `write_handshake/read_handshake` async over any AsyncRead+AsyncWrite, incoming-handshake infohash lookup callback (like Go's handshake.go for multiple torrents).
- `Message` enum covering BEP 3 + BEP 6 fast (HaveAll/HaveNone/Suggest/Reject/AllowedFast) + Port + Extended{id,payload} + BEP 52 HashRequest/Hashes/HashReject; zero-copy decoder (`bytes::Bytes` for Piece data) with max message length limit like Go; encoder writing into a reusable BytesMut buffer; a framed reader/writer pair with a write buffer and explicit flush (Go's peerConnMsgWriter semantics incl. the backported wakeup fix described in engine-go/patches/torrent/WEBTOR_PATCH.md).
- Extension protocol (BEP 10) handshake dict (m, v, p, yourip, reqq, metadata_size, ipv4/ipv6, upload_only), ut_metadata (BEP 9) request/data/reject incl. trailing data, ut_pex (BEP 11) added/added.f/dropped for v4/v6 with PexFlags; use wt_meta::bencode (ask coordinator / read wt-meta when it's published; until then code against its documented API in the wt-meta task: Value, decode, decode_prefix, encode).
- `mse` module: BEP-style Message Stream Encryption (DH 768-bit, RC4, crypto_provide plaintext/RC4, SKEY lookup for multiple torrents) initiator and receiver, header obfuscation policy like anacrolix defaults; returns a stream wrapper implementing AsyncRead+AsyncWrite.
- `utp` module: pure-Rust uTP sockets (connect/accept returning AsyncRead+AsyncWrite streams) sharing one UDP socket with other UDP users (DHT/UDP tracker need demux — expose a way to hand non-uTP packets back, like anacrolix shares the socket). You may use a maintained pure-Rust crate if it meets this, otherwise implement LEDBAT-congestion uTP.
- Dial/listen helpers for TCP and uTP on dual stack, honoring timeouts.
Constraints: no unsafe; no allocations per block on the hot path beyond Bytes refcounts; bounded buffers; cancel-safe futures.
Observable acceptance: port peer_protocol/*_test.go, mse/mse_test.go, handshake tests; MSE interop test between your initiator and receiver both directions; a uTP loopback test transferring 64 MiB with correct data and throughput >= 100 MB/s on loopback; codec benchmark (criterion or simple bench test) decoding Piece messages without copying payload.
